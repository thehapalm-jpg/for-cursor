## Как связано

nginx слушает TCP 443 и по SNI выбирает бэкенд. Имя сервера равно IP или пустое: `127.0.0.1:8443`, это панели. Имена `cloudflare.com`, `www.cloudflare.com`, `intel.com`, `www.intel.com`, `www.microsoft.com` и любой другой SNI: `127.0.0.1:4443`, это reality. Конфиг: `/etc/nginx/stream.d/sni.conf`. HTTP-80 только для проверки Let's Encrypt, корень `/var/www/acme`.

xray слушает `2053` (VLESS, TCP, TLS) и `4443` (VLESS, TCP, Reality). Подписки x-ui отдаёт по HTTP на порту `2096`. Путь подписки записан в настройках панели, в этот файл он не скопирован.

Amnezia: контейнер `amnezia-awg2`, образ собран локально поверх `amneziavpn/amneziawg-go`, привилегированный, проброс UDP 443, каталог ключей `/opt/amnezia/awg`, сеть `10.8.1.0/24`. Модуля ядра нет, работает userspace `amneziawg-go`. Код генератора: `/root/awg-web`, сервис `awg-web`. В `awgcore.py` и `app.py` адрес сервера прописан явно.

fail2ban: тюрьмы `sshd` и `3x-ipl`.

Сертификат Let's Encrypt выпущен на сам IP, профиль `shortlived`, клиент acme.sh, проверка через webroot. Продление в cron root: `52 1,7,13,19`. ## Если адрес снова перестанет открываться

Сначала проверить не из домашней сети: открывается ли `https://` на IP. Если снаружи открывается, а из России таймаут, машина жива. Консоль hip.hosting это подтверждает отдельно, она идёт мимо домашнего провайдера.

На сервере достаточно `fail2ban-client status`, `ufw status verbose` и `systemctl is-active nginx x-ui ssh`. Если службы активны и снаружи панель отвечает, нужен новый IP, а не починка панелей.

Новый VPS брать на 2 ГБ. В чат прислать IP и пароль root из карточки hip.hosting. Переносить настройки сервера и не переносить клиентские конфиги: они указывают на старый адрес. Это база 3x-ui без клиентов, nginx, Amnezia без пиров, генератор, ufw и fail2ban. Сертификат выпустить заново на новый IP. Потом заново создать `Osnova`, `TV`, `Nastya`, `Roma_Karshov` на `hiddify-tls`.
