# Подбор ноутбука для Насти 🛒

Игровой опросник без гигабайтов и прочей магии. Настя отвечает на простые вопросы —
ты получаешь понятную «карточку» ответов и по ней подбираешь **минимум 3 ноутбука**,
которые реально купить в РФ (DNS, М.Видео, Эльдорадо, Ozon, Wildberries).

## Что внутри

| Путь | Зачем |
|------|--------|
| `docs/ANKETA.md` | Текст анкеты — можно сразу переслать в Telegram/WhatsApp |
| `bot/` | Telegram-бот с кнопками (тот же опрос в формате игры) |
| `requirements.txt` | Зависимости Python |

## Вариант А — без бота (быстрее всего)

1. Открой [`docs/ANKETA.md`](docs/ANKETA.md).
2. Скопируй текст Насте.
3. Она отвечает буквами (`1б, 2а, 5а+в+д…`).
4. Пришли ответы сюда — подберём модели.

## Вариант Б — Telegram-бот

### 1. Создать бота

1. В Telegram открой [@BotFather](https://t.me/BotFather).
2. Команда `/newbot` → имя, например `Ноутбучная для Насти`.
3. Username, например `nastya_laptop_quiz_bot`.
4. Скопируй токен вида `123456:ABC-DEF...`.

### 2. Настроить проект

```bash
cd /path/to/for-cursor
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

В файл `.env` вставь:

```
BOT_TOKEN=твой_токен_от_BotFather
```

### 3. Запустить

```bash
python -m bot.main
```

Пока терминал открыт — бот живой. Настя пишет боту `/start` и тыкает кнопки.
В конце бот выдаст карточку ответов — её можно переслать тебе.

> Бот должен работать на машине с интернетом (твой ноут / VPS / домашний ПК).
> Токен никому не свети и не коммить `.env`.

О чём спрашиваем (22 вопроса, без техники):

- для кого ноутбук и какой опыт с компьютером  
- таскать с собой / вес / размер экрана «как пицца»  
- жизнь без розетки  
- задачи: интернет, фильмы, документы, фото/видео, игры, учёба  
- сколько окон открыто сразу, дети, куда складывать фото  
- созвоны, клавиатура, свет в комнате, сенсор/«перевёртыш»  
- флешки и телевизор, на сколько лет берём, марка  
- бюджет, приоритеты, Windows vs «яблоко», где покупать, срочность  

По ответам складывается профиль — и уже по нему рекомендации из магазинов РФ.
