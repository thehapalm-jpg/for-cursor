# Модули терапии

Каждый модуль — отдельная тренировка с своим `module_id` в Supabase.

| module_id | Папка | Статус |
|-----------|-------|--------|
| `song-therapy` | `../js/program.js` | активен |

Новый модуль:

1. Добавь `module_id` в `js/constants.js` или отдельный файл модуля.
2. Опиши программу (дни, фазы) по образцу `program.js`.
3. Данные пользователя хранятся в `user_module_data` автоматически — отдельная миграция не нужна.
