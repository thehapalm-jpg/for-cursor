# Песня — безопасный вход

Веб-интерфейс для терапии через письмо песен: **14 дней** с таймером, короткими тезисами на экране и полями для текста. Всё сохраняется локально в браузере.

## Запуск

```bash
cd song-therapy
python3 -m http.server 8080
```

Открой в браузере: http://localhost:8080

Или открой `index.html` напрямую (модули ES6 — лучше через локальный сервер).

## Режимы

| Режим | Когда |
|--------|--------|
| **День 1–14** | Полная программа: подготовка нервной системы + песня |
| **Быстрый вход** | Якорь 90 сек + песня. **Каждая сессия сохраняется отдельно** — кнопка «Сохранить сессию и начать новую» |

## Что внутри

- Тезисы на экране — не держать в голове
- Таймер на каждый шаг (Старт / Пауза / Готово)
- Липкие напоминания во время письма (меняются каждые 4 сек)
- Экспорт всех полей в `.txt`
- Прогресс и тексты — `localStorage`

## Не замена терапии

Инструмент для самостоятельных сессий, когда психотерапевт не рядом. Циталопрам и очные встречи — по плану врача.
